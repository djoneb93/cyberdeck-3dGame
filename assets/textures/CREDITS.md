# Crédits des textures

Les textures photographiques de ce dossier viennent d'**ambientCG** (https://ambientcg.com), sous licence **CC0 1.0** (domaine public).
L'image de couleur et la normal map (`*_n.jpg`, relief) de chaque matériau ont été gardées, réduites à 512 × 512 pixels ;
le jeu assombrit la couleur pour l'ambiance de nuit et dessine par-dessus les fenêtres, les néons et les marquages.
